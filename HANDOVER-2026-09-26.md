## 7. Operational Knowledge (how to do things here)
- **GSC API:** SA key `~/Downloads/themotivahub1717-598a0dffacbd.json`; scopes `webmasters`+`indexing` together required; URL Inspection answers unstable → sample ×2-3; sitemap feed endpoint 404s (use UI/inspection).
- **GA4 API:** camelCase only (`screenPageViews`, `activeUsers`, `engagementRate`, `averageSessionDuration`, `landingPage`, `pagePath`); `dateRanges` must be arrays; page-list filters: fetch `limit:300` + filter locally (complex filters rejected); dates `YYYY-MM-DD`.
- **Request Indexing flow:** user signs into Google inside the controlled browser window → Browser agent drives GSC UI. Agent never handles credentials. Quota 10/day.
- **Deploy polling:** needle = unique string from the new build; verify CSS version token `?v=` matches dist.
- **Verification gotchas:** ASCII apostrophe (0x27) breaks single-quoted JS strings; raw string counts include CSS selectors (use `class="..."` DOM regex); linked-CSS rules live in `dist/styles/global.css`; quote `[slug].astro` in zsh; html.unescape before needle matching; always `git diff` after SearchReplace.
- **FR pipeline:** every article paragraph is `<div data-i18n-html="article_slug_pN">` from `articles-fr.json` — body edits require matching keys; this is why citations must stay in frontmatter.
