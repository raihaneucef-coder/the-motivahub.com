📋 How to Use This Interface

  1. For each article, click the "Search Pexels" button to open the public Pexels search page.
  2. Browse the search results visually and find an image that matches the article's topic and selection criteria.
  3. Click on the image you want to open its Pexels photo page.
  4. From the photo page URL, extract:
    • Photo ID: the number in the URL, e.g. https://www.pexels.com/photo/1234567/ → ID is 1234567
    • Photographer name: shown below the image on Pexels
    • Photographer URL: link to their Pexels profile, e.g. https://www.pexels.com/@photographer-name
    • Direct image URL: right-click the image → "Copy Image Address" or inspect the src attribute. It should look like https://images.pexels.com/photos/1234567/pexels-photo-1234567.jpeg
  5. Enter the extracted information into the form below each article.
  6. Click "Save Selection" to store your choice locally in the browser.
  7. After saving all 9 selections, export the manifest using the button at the bottom.
